# Тест ОПП — 50 вопросов

Общий тест опытного производства поддонов: 50 новых вопросов из Excel преподавателя
(роботизация, линия ОПП, экономика производства, цифровые системы).

Сайт сделан на основе https://poddon.github.io/opp-pallet/ — тот же интерфейс, личный кабинет,
таймер, админ-панель и выгрузка результатов в Excel.

- Вопросы: `questions.js` (исходник — `OPP-voprosy-50.xlsx`)
- Скачать вопросы: `skachat-voprosy.html`
- Результаты и доступы хранятся отдельно от теста opp-pallet (свои ключи в браузере
  и своё пространство счётчиков), поэтому студенты, сдавшие старый тест, могут сдать этот.

## Публикация

Settings → Pages → Source: **GitHub Actions**. После каждого push в `main`
сайт публикуется автоматически (`.github/workflows/pages.yml`).

## PostgreSQL / Synology

Как в opp-pallet: `api.php` + `api-config.php`, `server.js`, `schema.sql`,
инструкции в `INSTRUKTSIYA-*.docx`.
