# База теста ОПП в Яндекс Облаке

Результаты, «живое» отслеживание, админ-панель и статистика хранятся в базе **YDB** в Яндекс Облаке.
Запросы принимает **функция Cloud Functions** (файл `index.js` из этой папки).
Серверы в России, HTTPS уже есть, ничего не надо держать включённым.

Всё делается в браузере, примерно за 15 минут.

---

## 1. Вход и платёжный аккаунт

1. Откройте https://console.yandex.cloud и войдите через Яндекс ID.
2. Консоль предложит создать **платёжный аккаунт** — привяжите карту.
   Деньги не списываются, пока вы укладываетесь в бесплатный объём (см. «Сколько это стоит»).
3. Будет создано облако и каталог `default` — дальше всё делаем в нём.

## 2. База данных YDB

1. В меню слева: **Managed Service for YDB → Создать базу данных**.
2. Имя: `opp`. Тип: **Serverless**. Остальное не трогайте → **Создать базу данных**.
3. Дождитесь статуса **Running**, откройте базу и на вкладке **Обзор** скопируйте строку
   **Document API эндпоинт** — она вида
   `https://docapi.serverless.yandexcloud.net/ru-central1/b1g.../etn...`

Таблицы создавать не нужно — функция создаст их сама.

## 3. Сервисный аккаунт и ключ

1. **Identity and Access Management → Сервисные аккаунты → Создать сервисный аккаунт**.
2. Имя: `opp-api`, роль: **ydb.editor** → **Создать**.
3. Откройте аккаунт `opp-api` → **Создать новый ключ → Создать статический ключ доступа** → **Создать**.
4. Скопируйте **Идентификатор ключа** и **Секретный ключ** (секрет показывается один раз).

## 4. Функция

1. **Cloud Functions → Создать функцию**, имя `opp-api` → **Создать**.
2. Среда выполнения: **Node.js 22** → **Продолжить** (галочку «Добавить файлы с примерами кода» можно снять).
3. Способ: **Редактор кода**. Создайте файл `index.js` и вставьте **целиком** содержимое
   файла `test/yandex-cloud/index.js` из GitHub.
4. Параметры:
   - Точка входа: `index.handler`
   - Таймаут: `10` секунд, Память: `128 МБ`
   - Сервисный аккаунт: `opp-api`
5. **Переменные окружения** (кнопка «Добавить переменную»):

| Ключ | Значение |
|---|---|
| `DOCAPI_ENDPOINT` | эндпоинт из шага 2 |
| `AWS_ACCESS_KEY_ID` | идентификатор ключа из шага 3 |
| `AWS_SECRET_ACCESS_KEY` | секретный ключ из шага 3 |
| `ADMINS` | `Лукьянчиков Егор Игоревич=пароль;Пышненко Кирилл Валерьевич=пароль` |

   В `ADMINS` — ФИО и пароль, с которыми администратор входит на сайте, через `=`;
   администраторов разделяйте `;`. Пароли — латиницей. Эти значения видны только вам в консоли.

6. **Сохранить изменения** и дождитесь, пока версия соберётся.
7. На вкладке **Обзор** функции включите **Публичная функция**.
8. Скопируйте **Ссылку для вызова**: `https://functions.yandexcloud.net/d4e...`

## 5. Проверка

Откройте в браузере: `ССЫЛКА?action=health`

| Ответ | Что значит |
|---|---|
| `{"ok":true,"db":"ydb","server":"yandex-cloud"}` | Всё работает, таблицы созданы |
| `Не задана переменная DOCAPI_ENDPOINT` | Не добавили переменную или опечатка в имени |
| `AccessDenied` / `403` | Неверный ключ или у аккаунта нет роли `ydb.editor` |
| `{"message":"Forbidden"}` | Функция не публичная (шаг 4.7) |

Если сама ссылка открывается, а сайт пишет об ошибке и в консоли браузера (F12) есть слово **CORS** —
проверьте, что сайт открыт с `https://poddon.github.io`. Другие адреса добавьте в переменную
`ALLOWED_ORIGINS` через запятую.

## 6. Переключить сайт

На GitHub (ветка `gh-pages`) откройте `test/synology-config.js` → карандаш **Edit** и впишите:

```js
window.OPP_DB_URL = "https://functions.yandexcloud.net/d4e...";
```

**Commit changes**. Через 1–2 минуты новые результаты пойдут в Яндекс Облако.
Вернуться на прежнюю базу — сделать строку пустой: `window.OPP_DB_URL = "";`.

## Где смотреть результаты

- На сайте: вход администратора → таблица, «живое» отслеживание, Excel.
- `statistics.html` — статистика и выгрузки в Excel.
- В консоли: **Managed Service for YDB → opp → Навигация → opp_results**.

## Сколько это стоит

У Cloud Functions и YDB Serverless есть **ежемесячный бесплатный объём**
(точные цифры — https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier).
Одна пара на 100 студентов — примерно 50–60 тысяч вызовов функции (сайт сообщает прогресс студента
раз в несколько секунд). Если бесплатный объём функций — 1 млн вызовов в месяц, его хватает
примерно на 15–20 таких пар.

Чтобы точно не было списаний: **Billing → Бюджеты → Создать бюджет** на 1 ₽ с уведомлением на почту.

## Важно

- Старые результаты из Supabase сами не переносятся — перед переключением скачайте их в Excel на `statistics.html`.
- Ключи и пароли храните только в переменных функции, **не** в файлах на GitHub.
