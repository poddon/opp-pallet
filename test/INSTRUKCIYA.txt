ТЕСТ ОПП — ЛОКАЛЬНЫЙ ЗАПУСК С POSTGRESQL
=======================================

Что нужно установить один раз
1. PostgreSQL: https://www.postgresql.org/download/windows/
   При установке задайте пароль для пользователя postgres и запомните его.
   Порт оставьте 5432.
2. Node.js (версия LTS): https://nodejs.org

Запуск (Windows)
1. Распакуйте архив в любую папку, например C:\opp-test
2. Дважды щёлкните START.bat
3. В первый раз откроется Блокнот с файлом db-config.json.
   Вместо СЮДА_ПАРОЛЬ_ОТ_POSTGRES впишите пароль postgres, сохраните, закройте.
4. Снова запустите START.bat. Сервер сам создаст базу opp_test и таблицы,
   а браузер откроет сайт: http://127.0.0.1:8787
   Окно с сервером не закрывайте, пока идёт тест.

Студенты с других компьютеров
В окне сервера будет строка «Для студентов в той же сети: http://192.168.x.x:8787».
Эту ссылку открывают студенты в той же сети (Wi-Fi колледжа).
Если не открывается — разрешите Node.js в брандмауэре Windows (частные сети).

Проверка базы
http://127.0.0.1:8787/api.php?action=health  →  {"ok":true,"db":"postgresql"}

Где смотреть результаты
- На сайте: вход под ФИО администратора → таблица и кнопка «Скачать таблицу Excel».
- В pgAdmin: база opp_test → таблица quiz_results.
  SELECT * FROM quiz_results ORDER BY id DESC;

Что хранится в базе
quiz_results  — результаты прохождений
fio_done      — кто уже сдал (одно ФИО — одна попытка)
fio_grants    — разрешения на повторную попытку однофамильцам
module_access — открыт ли тест

Новые вопросы: замените questions.js (формат прежний) и перезапустите страницу.
