Открыть тест для групп

Всем выбранным группам назначается общий тест по всем модулям.

Выбранные группы

Выберите направление, впишите год и номер группы и нажмите «Добавить в список».

    Активные тесты

    Тест закрывается автоматически по окончании времени доступа. Кнопка «Закрыть тест» закрывает его раньше только для выбранной группы.
