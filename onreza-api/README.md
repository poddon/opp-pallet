# ОПП — ONREZA PostgreSQL API

Подготовлено для перевода сайта ОПП с Supabase на собственную PostgreSQL в России.

## Развёртывание

1. На https://app.onreza.ru создайте workspace и PostgreSQL на бесплатном тарифе.
2. Создайте Compute-приложение из репозитория `poddon/opp-pallet` с корнем `onreza-api` (если сервис поддерживает указание корневой папки; иначе используйте отдельный репозиторий).
3. Подключите PostgreSQL как интеграцию к приложению, чтобы задать `DATABASE_URL`.
4. В PostgreSQL выполните `schema.sql` в редакторе SQL.
5. Задайте переменные окружения `ADMIN_NAME`, `ADMIN_PASSWORD_HASH` (SHA-256 пароль), `ALLOWED_ORIGINS=https://poddon.github.io`.
6. Проверьте `https://<ваш-домен>/health` — должен вернуть `{"ok":true,"db":"connected"}`.
7. Только после этого замените адрес API на сайте и испытайте тест с нескольких устройств.

### Примечания о безопасности

* Не размещайте `DATABASE_URL` и пароль администратора в GitHub или JavaScript браузера.
* PostgreSQL должна принимать соединения только по TLS, а сайт обращаться к API по HTTPS.
* Публичные POST endpoints нуждаются в rate limiting, защите от массовых ложных отправок и серверной выдаче сессионных токенов, прежде чем собирать настоящие персональные данные.
* Пароли и учётные записи существующего Supabase не переносятся автоматически.
* Данные старой базы также НЕ перенесены.
* Бесплатный тариф имеет usage-credit: при исчерпании сервис может остановиться.
* Договор с обработчиком ПДн, трансграничная передача через GitHub Pages и правовые основания сбора ФИО требуют отдельного согласования.

Документация: https://docs.onreza.ru/compute.html и https://docs.onreza.ru/integrations/postgresql/
