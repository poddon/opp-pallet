# Общее хранение результатов теста

GitHub Pages не умеет сохранять данные участников. Файл worker.js — серверное API для Cloudflare Workers, schema.sql — схема Cloudflare D1.

1. Создайте D1 database в Cloudflare; примените schema.sql.
2. Создайте Worker с кодом worker.js и привяжите D1 к переменной DB.
3. Задайте секрет ADMIN_KEY (случайный длинный пароль), переменную ALLOWED_ORIGIN=https://poddon.github.io.
4. На странице test/index.html загрузите script с window.OPP_API="https://<your-worker>.workers.dev" перед app.js.
5. Админский API должен получать X-Admin-Key; пароль храните только у преподавателя, не вставляйте в публичные файлы GitHub. В текущем клиенте заголовок не настроен — для полноценного включения потребуется эта интеграция.
6. Проверьте два устройства и экспорт после прохождения. Пока шаги 1–5 не сделаны, результаты остаются локальными.

Не используйте файл с паролем для публикации на GitHub Pages. Ранее сохранённые локальные результаты автоматически не переносятся.
